# Правила для агентов

Перед работой прочитайте: `00_Направление.md`, `01_Вопросы_к_экспертам.md`, `02_Гипотезы.md` и `03_Журнал_решений.md`.

- Считайте утверждение фактом только при ссылке на материал из `evidence/`.
- Мнение одного эксперта помечайте как мнение, не как общее правило.
- Сначала добавляйте необработанные данные в `inbox/` или `evidence/`; не переписывайте канонические документы без основания.
- Для каждого вывода указывайте: источник, дату, уровень уверенности и следующий проверочный вопрос.
- Не удаляйте чужие материалы. При конфликте фиксируйте расхождение в `01_Вопросы_к_экспертам.md`.
