# База контекста проекта

Эта папка — единый проверяемый контекст для команды, экспертов и ИИ-агентов.

## Порядок работы

1. Новые ответы и материалы сначала попадают в `inbox/` или `evidence/`.
2. Факты, гипотезы и решения не смешиваются.
3. Изменение канонических файлов должно ссылаться на источник в `evidence/`.
4. Неопределённость фиксируется явно; агент не заполняет пробелы догадками.

## Навигация

- `00_Направление.md` — цель, пользователи, границы.
- `01_Вопросы_к_экспертам.md` — что нужно выяснить.
- `02_Гипотезы.md` — предположения, ожидающие проверки.
- `03_Журнал_решений.md` — принятые решения и основания.
- `05_Словарь_ниши.md` — термины и определения.
- `evidence/` — проверяемые свидетельства.
- `inbox/` — неразобранные входящие материалы.
- `templates/` — шаблоны для экспертов и агентов.
